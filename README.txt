OPPOSITE WORLD LAB
Open index.html in any browser. No internet or install needed.

WHAT IS "WRONG" ON PURPOSE
1. OMR sheet     - fills a different bubble than you click (dashed ring shows your real click); score uses the wrong sheet.
2. D-pad         - Up=Left, Left=Up, Down=Right, Right=Down (buttons and arrow keys when the grid is focused).
3. Counter       - Add subtracts, Subtract adds, Reset sometimes sets 7.
4. Volume slider - slide right = quieter.
5. Keyboard      - each letter typed becomes the next letter.
6. Sorter        - "Ascending" sorts descending; "Descending" shuffles.

To change a behavior, edit the commented section for that tool in the <script>.
